# Logistics EDA & Visualization — Internship Task 1

This repository demonstrates exploratory analysis of a **hypothetical** logistics dataset.

## Run
```bash
pip install -r requirements.txt
python scripts/eda_analysis.py
```

## Contents
- `data/hypothetical_logistics_data.csv` — 500 simulated shipments
- `scripts/eda_analysis.py` — reproducible EDA and visualization code
- `visualizations/` — six generated charts
- `reports/analysis_summary.md` — key findings
- `REPORT_DESCRIPTION.txt` — submission description

## Tools
Python, pandas, NumPy, Matplotlib.

## Important
The dataset and numerical findings are simulated for academic/internship demonstration and do not represent real logistics-company performance.
